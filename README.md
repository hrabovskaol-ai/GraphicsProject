# \# Оцінка щільності міської забудови за супутниковими знімками

# 

# Цей проєкт реалізує автоматизований конвеєр (пайплайн) для обробки супутникових RGB-зображень з метою класифікації територій та оцінки відсотка герметизованого ґрунту (штучних покриттів: будівель, доріг, асфальту).

# 

# Проєкт розроблено з дотриманням вимог до освітніх STEM-проєктів: усі алгоритми обробки (гістограмне вирівнювання, фільтрація, порогова сегментація) реалізовані вручну за допомогою матричних операцій без використання високорівневих функцій бібліотек комп'ютерного зору (наприклад, OpenCV).

# 

# \## Опис Пайплайну №1

# 

# Конвеєр обробки складається з 4 послідовних стадій:

# 

# 1\. \*\*М'яке гістограмне вирівнювання\*\* (`1.1\_histogram\_image.png`): Покращує контрастність зображення для кращого розділення об'єктів. Використовується змішування оригінального та вирівняного зображень (за замовчуванням 50/50), щоб уникнути "випалювання" природних кольорів ґрунту.

# 2\. \*\*Колірне перетворення\*\* (`1.2\_color\_exg.png`): Розрахунок вегетаційного індексу ExG (Excess Green) за формулою `2G - R - B`. Дозволяє математично виділити зони з рослинністю.

# 3\. \*\*Просторова фільтрація\*\* (`1.3\_filter\_exg\_filtered.png`): Згладжувальний прямокутний фільтр (Box Filter), реалізований через матричні зсуви. Усуває високочастотний шум ("сіль і перець") на карті індексу, вирівнюючи контури будівель.

# 4\. \*\*Порогова сегментація\*\* (`1.4\_segmentation\_mask.png`): Автоматична бінаризація згладженої карти індексу за класичним методом Оцу. Формує фінальну маску, де білий колір відповідає забудові, а чорний — зеленій зоні.

# 

# 

# 

# \## Налаштування параметрів (Конфігурація)

# 

# Основні параметри алгоритмів винесені у верхню частину коду для зручного налаштування без втручання в логіку функцій:

# 

# \* \*\*`GSD`\*\* (Ground Sample Distance): Роздільна здатність знімка у метрах на піксель (за замовчуванням `0.3` для датасету UC Merced). Використовується для розрахунку реальної площі.

# \* \*\*`ROI`\*\* (Region of Interest): Можливість задати кортеж `(x, y, ширина, висота)` для аналізу лише певної ділянки зображення. `None` — обробка всього кадру.

# \* \*\*`EQ\_STRENGTH`\*\*: Коефіцієнт (від `0.0` до `1.0`), що визначає силу гістограмного вирівнювання на першій стадії.

# \* \*\*`FILTER\_SIZE`\*\*: Розмір ядра для Box Filter (за замовчуванням `5` для матриці 5x5). Більше значення дає сильніше згладжування, але розмиває краї будівель.
